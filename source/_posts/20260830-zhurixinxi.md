**三、主日敬拜诗歌:**


**诗歌一：万福泉源歌**

{% asset_img 万福泉源歌.jpg %}

<audio src="万福泉源歌.mp3" controls style="max-width: 100%; width: 100%;"></audio>

1.全能上帝，万福泉源，
恳求垂听我赞美。
上帝恩典似水长流，
我们高声颂恩惠。
愿主教我唱诗和谐，
犹如天使颂主前。
上帝恩典实无穷尽，
主的慈爱不变迁。

2.我的一生有主引导，
时时刻刻蒙主恩。
只求上帝永不离我，
直到进入天家门。
有时如羊迷失正路，
主如牧者来找寻。
救我脱离一切危险，
为我流血舍性命。

3.救主洪恩实在高深，
万分之中难报一。
慈悲救主恳求助我，
侍奉上帝尽我力。
我深知道我心软弱，
容易离开我上帝。
今将身心献为活祭，
恳求收纳莫丢弃。阿们。



**诗歌二：万古磐石为我开**

{% asset_img 万古磐石为我开.jpg %}

<audio src="万古磐石为我开.mp3" controls style="max-width: 100%; width: 100%;"></audio>

1.万古磐石为我开，
容我藏身在主怀，
兵丁举枪伤主胁，
立时流出水与血，
双重医治我罪过，
罪刑罪权皆得脱。

2.纵然勤劳不罢休，
亦不能达主要求，
纵然心能以持久，
纵眼泪永远淌流，
仍不能赎我罪尤，
惟有主能施拯救。

3.两手空空到主前，
只有紧依十架边，
赤身求主赐衣服，
无依靠望主恩助，
污秽奔至活泉旁，
求主洗我免灭亡。

4.当我今生年日逝，
到临终双目垂闭，
当飞上华美天堂，
觐见主在宝座上，
万古磐石为我开，
容我藏身在主怀。

**回应诗歌：爱人如己**

{% asset_img 爱人如己.jpg %}

<audio src="爱人如己.mp3" controls style="max-width: 100%; width: 100%;"></audio>

圣洁和公正的律例，
就是要爱人如自己。
不可埋怨本国的子民，
不可心里恨你的兄弟。

靠着圣灵凭着信心，
就是要爱人如自己。
要用爱心互相服侍，
不可自由放纵情欲。

惟有耶稣，惟有耶稣
为爱罪人牺牲自己
不求成就自己的意思，
只求遵行天父的旨意。

惟有耶稣，惟有耶稣
为爱罪人牺牲自己
他的大爱完全了律法，
让世界彻悟爱的真谛。



**奉献诗歌：成为我异象**

{% asset_img 成为我异象.jpg %}

<audio src="成为我异象.mp3" controls style="max-width: 100%; width: 100%;"></audio>

1.求我心中王，成为我异象，
我别无爱慕，惟主我景仰！
充满我思想，我心向往，
睡着或睡醒，慈容是我光。

2.成为我智慧，成为我箴言，
我愿常跟随，祢在我身边。
祢是我天父，我是祢子，
祢常居我心，我与祢合一。

3.我不求虚名，也不求富有，
祢是我基业，从今到永久。
惟祢在我心，永远居首，
天上大君王，祢是我万有。

4.天上大君王，光明的太阳，
容我享天乐，我已打胜仗。
我心属祢心，永无变更，
万有的主宰，成为我异象。
